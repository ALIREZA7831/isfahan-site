# اصفهان | نصف جهان

وب‌سایت فارسی و راست‌چین معرفی اصفهان، با صفحات داخلی برای جاهای دیدنی.

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای انتشار، همه فایل‌ها و پوشه `images` را در یک مخزن GitHub قرار دهید و GitHub Pages را از شاخه `main` و پوشه `/ (root)` فعال کنید.

## ساختار
- `index.html`: صفحه اصلی
- `places.html`: فهرست دیدنی‌ها
- `about.html`: معرفی اصفهان
- فایل‌های `*.html`: صفحات معرفی مکان‌ها
- `style.css`: ظاهر و چیدمان واکنش‌گرا
- `script.js`: منوی موبایل و انتخاب صفحه فعال
- `images/`: تصویرها و تصویرسازی‌های محلی

تصویر کاخ چهلستون از فایل موجود در پروژه اولیه نگه داشته شده است. برای چند مکان دیگر از تصویرسازی‌های SVG محلی استفاده شده تا سایت بدون لینک تصویر خارجی و بدون تصویر شکسته اجرا شود. فونت Vazirmatn در صورت اتصال به اینترنت از Google Fonts بارگیری می‌شود و در حالت آفلاین فونت جایگزین نمایش داده می‌شود.
